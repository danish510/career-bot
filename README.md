# 🤖 Bot Penasihat Karir Discord

## 📌 Deskripsi Proyek

Bot Penasihat Karir adalah bot Discord yang membantu pengguna menemukan rekomendasi profesi berdasarkan minat dan keterampilan mereka. Bot ini dapat memberikan saran karir yang sesuai dan membantu pengguna memahami jalur yang bisa mereka ambil.

Proyek ini dibuat sebagai Proyek Kelulusan.

---

## 🎯 Tujuan Proyek

Tujuan dari proyek ini adalah:

* Membantu pengguna menemukan rekomendasi karir
* Menerapkan pemrograman Python dalam proyek nyata
* Membuat bot Discord interaktif menggunakan Discord API
* Melatih penggunaan GitHub untuk manajemen proyek

---

## ⚙️ Fitur Bot

Fitur utama bot:

* Memberikan rekomendasi karir
* Menggunakan tombol interaktif
* Merespon perintah pengguna
* Memberikan informasi deskripsi karir

Contoh penggunaan:

User memilih: "Saya suka teknologi"

Bot menjawab:

"Karir yang cocok:

* Programmer
* Web Developer
* Data Scientist"
